# Air Combat
Node 20+ required.

## Local
npm install
Set IP_HASH_SALT to a long random secret.
npm start
Open http://localhost:3000

## Public
Deploy this Node/Express app to a Node-capable host and set IP_HASH_SALT. The included JSON storage is a starter; for many users use a managed database and secure server sessions.

## Street Legends
Deploy the standalone car game as a Render Static Site using the root `render.yaml` Blueprint:

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/yarin51013-source/shooting-aircrafts)

The Blueprint publishes `docs/street-legends` as a separate site. It does not replace the Air Combat app.
